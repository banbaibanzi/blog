升级依赖 ​

1.全局安装插件 ​

js
npm install -g npm-check-updates
1

2.检查更新 ​

js
ncu //	完整	npm-check-updates
1

3.更新package.json文件中的版本 ​

此命令是更新 package.json ，真正的依赖包还没有下载，需要删除 node_modules 重新 install

js
ncu -u
1

4.安装最新依赖 ​

js
npm install
1
